One-time setup needed: connect Resend

  1. Sign up free at resend.com with hello@debtfreeempire.com (3,000 emails/month free).
  2. In Resend, open Domains → Add Domain → debtfreeempire.com, add the DNS records it shows at your domain host, and wait for Verified.
  3. Open API Keys → Create API Key (permission: Sending access). Copy the key.
  4. In Terminal, from the website folder, run vercel env add RESEND_API_KEY production and paste the key.
  5. Redeploy so the key takes effect.
